# 执行路径与任务拆分

版本：v0.4；日期：2026-10-30。本文将已定设计拆成实施顺序与可交接任务，不新增产品范围，也不表示已经开始安装或开发。

规范以[产品需求](01-product-requirements.md)、[系统架构](03-system-architecture.md)和[交付与验收](05-delivery-and-acceptance.md)为准；实现取舍与待确认扩展见[决策记录](06-decisions-and-risks.md)。任务粒度是 M1 实验前的初始分解，实际适配量和工期须在接口缺口明确后修订，不预估“装包即完成”。

## 1. 当前起点与执行边界

- M0 已有 v0.4 文档基线和静态验证；M1–M5 尚未实施。本文全部 31 项实施任务均为**未开始**，不能把任务拆分或文档测试通过标成产品交付完成。
- 首期目标仍是中央 dsh + Coder、本地与远程项目绑定、现有侧边栏、会话内 CLI 交互和真实手机闭环；单份中央 code-server 独立放在第二阶段。
- 当前先做 T-101，再做 T-102。二者只读核查已指定的文档、元数据与安装产物，不安装、不登录、不改运行配置，不复制密钥或完整账号材料。
- T-103 起涉及安装、资源创建、测试账号、Host key 信任或外部服务操作的步骤，必须先获对应测试范围的授权。提交本文到 GitHub 不构成实验、部署、销毁或生产升级授权。
- 使用独立 profile、空目录和专用测试资源；下载物视为不可信，脚本与下载目录分开。实例／文件标记使用无敏感内容的随机值，凭据仅传受保护引用，不写入文档、日志或模型上下文。
- 产品内重建／销毁／凭据替换入口、跨设备草稿同步、新身份服务和公网暴露仍是待确认扩展；不添加对应 P0 实现任务。未提供入口的服务端拒绝，以及平台外部变化后的旧绑定失效仍须验收。

## 2. 运行时路径：一次操作实际经过哪里

这里的“运行路径”是调用链；后文 P-A 至 P-F 是交付工作流，两者不要混用。每条远程路径均受主体授权、绑定版本和当前认证通道身份约束，不允许由公开 cwd 或模型参数选择中央执行器。

| 路径 | 调用链与目标 | 主要实施任务 | 必守边界 |
|---|---|---|---|
| R-L 本地项目 | 会话／UI → 绑定解析 → 原本地 provider → 本地项目 | T-201、T-208、T-401 | 保留本地行为；只能从明确本地绑定进入，不能作为远程失败后备 |
| R-C 环境管理 | 已认证主体 → Coder 连接器 → 平台工作区／模板／Agent → 实例记录 | T-104、T-105、T-202、T-302 | 创建／启动／停止按授权执行；平台 running 不等于执行通道已就绪 |
| R-F 远程文件 | 工具／Host API／侧边栏 → 绑定文件服务 → 已核验 helper／适配器 → 目标根目录 | T-203、T-205、T-305 | 内部 anchor 与公开 cwd 分开；受管保存校验版本；外部直接写盘的竞争限制单独披露 |
| R-X 远程进程 | 模型 Shell／后台任务／PTY → 绑定执行服务 → 已启用远程通道 → 目标进程 | T-204、T-206、T-303 | 通常优先 helper；每进程 SSH 兼容路由仅按实测需要启用，未启用路径必须拒绝；不能把中央传输 PID 当远端任务身份 |
| R-I CLI 交互 | 原远端任务事件 → 中央绑定请求 → 有权用户在会话回答 → 原任务消费 | T-206、T-306、T-307 | request／任务／绑定／主体一致且仅消费一次；过期、换世代和跨绑定响应拒绝，不用终端输入冒充会话审批 |
| R-S 中央 IDE | 已认证深链接 → 单份中央 code-server → 合格远程连接层 → 原项目环境 | T-501、T-502、T-503 | 仅第二阶段；同时验证文件和执行位置，不以逐环境 code-server、文件复制或单独文件挂载替代 |

Git status／Diff、搜索与文件引用虽然展示在 R-F 的 UI 中，其底层命令仍须走 R-X 的相同绑定。不存在“侧边栏用本地 Git、Agent 用远端 Shell”的例外。新增执行通道必须先进入能力矩阵，分别验收取消、恢复、超时与重传策略；不能因已有 helper 就自动放行所有 subprocess 调用。

## 5. 任务领取、证据与交接

每次只领取前置已验证且授权齐备的任务。可并行任务也不得共享会被停止、重建或改凭据的夹具；共享接口变更先回到对应契约任务协调，不在不同分支分别猜测。上述任务是交接边界，不要求一项只能有一个代码提交。

任务执行时记录以下字段；结果不得仅放在终端滚屏中：

| 字段 | 必须记录的内容 |
|---|---|
| 身份与状态 | 任务 ID、执行者角色、关联代码提交；未开始／进行中／阻断／已验证，阻断原因与解除条件 |
| 前置与授权 | 前置任务证据、允许的 profile／控制面／工作区／网络目标、资源上限、允许动作与不可触碰的生产对象 |
| 输入与改动 | 版本／来源／完整性、模板与实例身份、修改模块、实际启用通道；秘密仅留受保护引用 |
| 验证与数据 | 命令和脱敏输出、对应 SC／CK、实际存储及远端读回、取消与资源清理事实；窗口内外和模拟／真实设备分别标注 |
| 结果与交接 | 通过／失败／未执行／环境不支持，已知限制、后继任务是否可启动；涉及范围变化时返回决定，不静默缩小 P0 |

运行原始证据保存在独立测试输出目录，提交前只选择脱敏、人工核对过的摘要与索引；不得把整个账号目录、日志目录或真实项目内容作为任务产物提交公开仓库。任务被阻断时先保留事实、命名原因再修复验证；未知远端任务和未确认取消不能以清理脚本直接掩盖。
